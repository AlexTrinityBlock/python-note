questions.json — QUESTION BANK (plain-text JSON template)
==========================================================

Each <TopicID>/questions.json is an array of question objects. Fields:

- type:        "single" or "multiple"
- question:    question text; Markdown supported. Fenced code blocks allowed —
               use a generic language tag or the target language tag.
- options:     array of option texts (inline Markdown allowed)
- answer:      array of 0-based indices of the correct options
- explanation: Markdown; must teach the whole knowledge module, with a code
               example when applicable, and derive any output step by step

Notes
-----
- Newlines inside JSON strings are written as \n.
- Wrap code identifiers in backticks so underscores are not parsed as emphasis.
- Scatter correct answers (no repeated positions, no detectable patterns).
- When options are reordered, update the answer indices AND every option-letter
  reference inside the explanation.

EXAMPLE BANK (replace all content; keep the shape)
--------------------------------------------------

[
  {
    "type": "single",
    "question": "<Short concept question about the topic>",
    "options": [
      "<Option A>",
      "<Option B — correct>",
      "<Option C>",
      "<Option D>"
    ],
    "answer": [1],
    "explanation": "<Complete explanation: the concept, why the correct option is right, and why each wrong option is wrong>"
  },
  {
    "type": "single",
    "question": "What does the following code print?\n\n```<language-tag>\n<code snippet in the target language>\n```",
    "options": [
      "<Option A>",
      "<Option B>",
      "<Option C — correct>",
      "<Option D>"
    ],
    "answer": [2],
    "explanation": "<Present the full concept with its own complete code example, then trace the execution step by step (state-change table + numbered walkthrough) to the correct output>"
  },
  {
    "type": "multiple",
    "question": "Which of the following statements about <concept> are true?",
    "options": [
      "<Correct statement>",
      "<Correct statement>",
      "<Incorrect but plausible statement>",
      "<Correct statement>"
    ],
    "answer": [0, 1, 3],
    "explanation": "<Explain every option completely, including why each incorrect option is wrong>"
  }
]

KNOWLEDGE QUESTIONS (no code required)
--------------------------------------

Pure-knowledge single-choice: exactly one correct index in "answer".
Pure-knowledge multiple-choice: two or more correct indices in "answer".
Both must explain every option, including why each wrong option is wrong.
