topics.json — TOPIC LIST (plain-text JSON template)
====================================================

Array of topic objects shown on the entry page hub. Fields:

- id:          directory name of the topic; unique, safe URL/path segment
- name:        display name
- description: short summary shown under the topic name

Replace <TopicID>, <Topic Name>, <Short description> and add/remove
entries freely. Keep the shape: an array of objects with exactly
"id", "name", "description".

[
  {
    "id": "<TopicID>",
    "name": "<Topic Name>",
    "description": "<Short description of the topic>"
  },
  {
    "id": "<AnotherTopicID>",
    "name": "<Another Topic Name>",
    "description": "<Short description of the topic>"
  }
]
